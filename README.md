# Jupyteach

Jupyteach is a learning management system (LMS) built for teaching and learning data science with Python. It was created by [Spencer Lyon](https://github.com/sglyon) and the Valorum Data team, and is being adopted as a QuantEcon open source project.

Read the introduction: [Introducing Jupyteach](https://blog.valorumdata.com/introducing-jupyteach/).

## Features

- Course, user, and role management (instructors, TAs, students)
- Content blocks: Jupyter notebooks, videos, markdown, assignments, links, and quizzes
- Auto-graded quizzes: single/multiple selection, code challenges, and fill-in-the-blank questions
- Interactive, in-browser notebook execution via [JupyterLite](https://jupyterlite.readthedocs.io/) — no installation or server management required
- Announcements and discussion threads

## Technology

Jupyteach is built with [Elixir](https://elixir-lang.org/) and the [Phoenix](https://www.phoenixframework.org/) web framework, running on Erlang/OTP (BEAM).
